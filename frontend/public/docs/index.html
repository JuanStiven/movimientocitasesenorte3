1. ¿Qué es Reporte Citas?

Reporte Citas es el tablero de analítica de la ESE Norte 3 que reemplaza la vista de Power BI ("Análisis General Asignación de Citas" y "Análisis Personal Asistencial"). Permite hacer seguimiento al movimiento de citas médicas a partir del cargue diario de los archivos insumo (Excel/CSV).

¿Para qué le sirve?

  • Consultar indicadores de asignación y atención de citas por sede, convenio y especialidad.
  • Detectar alertas: citas que llevan más de 3 días en estado EN SALA.
  • Analizar el desempeño del personal asistencial.
  • Exportar reportes en CSV para gerencia y toma de decisiones.
  • Importar datos diariamente sin depender de procesos manuales.
✅ Ventaja: los datos quedan guardados en base de datos (acumulado histórico), no se pierden al cambiar de archivo ni dependen de una conexión a Power BI.

2. Cómo ingresar

  1. Abra su navegador (Chrome, Edge o Firefox) e ingrese a la dirección del sistema: http://reportecitas.esenorte3.lat
  2. Escriba su usuario y su contraseña.
  3. Presione el botón “Iniciar Sesión”.
🔐 Si no recuerda su contraseña, solicítela al administrador del sistema o al área de sistemas de la ESE. Por seguridad, no comparta sus credenciales con otras personas.

4. Análisis General

Es la vista principal del sistema. Muestra el panorama del movimiento de citas con indicadores y gráficos (barras, tortas y tendencias).

Cómo usarla

  1. Presione el botón “Abrir/Cerrar Filtros” para mostrar las opciones de filtrado (por fechas, sede, convenio, estado, etc.).
  2. Seleccione los valores que necesita y el tablero se actualizará automáticamente.
  3. Revise los indicadores superiores: total de citas, asignadas, atendidas, pendientes y porcentajes clave.
  4. Analice los gráficos para identificar el comportamiento de la demanda.
✅ Consejo: combine filtros de fechas y sede para comparar periodos o territorios específicos.

5. Personal Asistencial

Permite consultar la producción y el desempeño de cada médico o profesional de salud.

  1. Use el buscador “Buscar por nombre de médico…” para localizar a un profesional.
  2. Consulte sus indicadores: citas asignadas, atendidas, ausencias y cumplimiento.
  3. Presione “Exportar CSV” para descargar la información en Excel.

6. Alertas Sala

Esta sección resalta automáticamente las citas que llevan más de 3 días en estado EN SALA, para que el equipo pueda intervenirlas a tiempo.

⚠️ Importante: estas alertas se generan de forma automática con los datos cargados. Si una cita aparece en alerta, debe gestionarse con el área responsable de salas.

7. Detalle Citas

Listado completo y paginado de las citas, ideal para búsquedas puntuales o auditoría de casos específicos.

  1. Use el buscador “Buscar por paciente, médico o sede…”.
  2. Navegue entre páginas con los botones de paginación (el total de registros se muestra en pantalla).
  3. Presione “Exportar CSV” para descargar el detalle filtrado.

8. Cargar Insumo (importación diaria)

Es el paso más importante del día: aquí se importa el archivo de citas (Excel o CSV) para que el tablero se actualice.

  1. Vaya a la sección “Cargar Insumo”.
  2. Seleccione el archivo del día (Excel o CSV) con el botón de importación.
  3. El sistema reconoce automáticamente las columnas del archivo (mapeo automático).
  4. Confirme la importación. Los datos quedan acumulados en la base de datos.
  5. Verifique que las demás secciones (Análisis General, Alertas, etc.) reflejen la información nueva.
📄 Formato: utilice el mismo formato de archivo insumo que se entrega diariamente (columnas de convenios EBS, estado de cita, estado de consulta, especialidad, entre otras).
✅ Consejo: cargue el insumo todos los días al inicio de la jornada para que los indicadores y alertas estén siempre al día.

9. Gestión de Usuarios

Disponible para administradores: permite crear cuentas, asignar roles y controlar quién ingresa al sistema.

  1. Ingrese a “Gestión de Usuarios” desde el menú superior.
  2. Presione el botón para crear un nuevo usuario.
  3. Diligencie los datos (nombre, usuario, contraseña y rol).
  4. Guarde los cambios. El nuevo usuario podrá iniciar sesión de inmediato.
⚠️ Solo los usuarios con rol de administrador pueden crear o modificar cuentas. Las contraseñas se almacenan de forma segura.

10. Consejos y buenas prácticas

  • Cargue el insumo a diario para mantener los indicadores y alertas actualizados.
  • Revise las Alertas Sala cada mañana para intervenir a tiempo las citas demoradas.
  • Use los filtros para comparar sedes, convenios y especialidades; no se quede solo con el total general.
  • Exporte el CSV cuando necesite trabajar la información en Excel o compartirla con Gerencia.
  • Cierre sesión cuando termine de usar el sistema, especialmente en computadores compartidos.

11. Preguntas frecuentes

¿Cada cuánto se actualizan los datos?

Los datos se actualizan cada vez que se carga el insumo del día. El sistema conserva el acumulado histórico en base de datos.

¿Qué pasa si subo un archivo con un formato diferente?

El sistema intenta reconocer automáticamente las columnas. Si el archivo no es compatible, se mostrará un mensaje indicándole qué ajustar.

¿Puedo recuperar el insumo anterior después de cargar uno nuevo?

Sí. Use la opción “Recargar insumo inicial” si necesita volver a procesar el archivo de referencia.

¿Quién puede crear usuarios?

Únicamente los usuarios con rol de administrador.

¿Dónde pido ayuda si tengo un problema?

Comuníquese con el área de sistemas / soporte técnico de la ESE Norte 3 e indique el mensaje o la pantalla que le generó la novedad.
